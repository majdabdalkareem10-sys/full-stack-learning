# FrontEndCourse - HTML learning notes

This folder contains my practice code from the Front End course.
I kept the original lesson folders and added simple comments to help me review later.

## HTML lectures

| Folder | What I practiced |
| --- | --- |
| `html/L2` | Images, local/online links, `href`, `target="_blank"`, separate HTML pages |
| `html/L3` | HTML page structure, headings, and `iframe` with YouTube, a local page and Google Maps |
| `html/L4` | Metadata, favicon, tables, `rowspan`, `colspan`, lists, `div` and `span` |
| `html/L5` | Forms, labels, input types, validation attributes, radio, checkbox, select and `name` |

## How I can run the files

Open any lesson folder in VS Code and open its `index.html` using Live Server, or open the file in a browser.
For `L5`, I can also open `inType.html` and `name.html` separately.

The images in `html/L2/imgs` and `html/L4/web.png` are kept from the original folder.
Some embedded websites and online images need an internet connection.
